# 1.2 傅里叶变换与频谱分析

**核心问题：** 傅里叶变换是什么？为什么它这么重要？

---

## 傅里叶变换的直观理解

### 核心思想

**任何信号都可以表示为不同频率正弦波的叠加。**

$$x(t) = \sum_{k} A_k \sin(2\pi f_k t + \phi_k)$$

其中：
- $A_k$：第k个正弦波的幅度
- $f_k$：第k个正弦波的频率
- $\phi_k$：第k个正弦波的相位

### 为什么这很重要

1. **分解复杂信号**：把复杂信号分解成简单的正弦波
2. **找出规律**：看哪些频率成分强，哪些弱
3. **滤波**：去掉不想要的频率成分

## 复数基础回顾

**重要提示：** 傅里叶变换使用复指数 $e^{-j2\pi ft}$。如果你对复数不熟悉，请先阅读 [附录A.3 复数基础](../appendix/A_math_reference.md#a3-复数基础)。

关键概念：
- 欧拉公式：$e^{j\theta} = \cos\theta + j\sin\theta$
- 复指数 $e^{j2\pi ft}$ 同时编码了信号的幅度和相位
- 傅里叶变换的结果 $X(f)$ 是复数，包含幅度和相位信息

## 数学表达

### 连续傅里叶变换（CFT）

**正变换：**
$$X(f) = \int_{-\infty}^{\infty} x(t) e^{-j2\pi ft} dt$$

**逆变换：**
$$x(t) = \int_{-\infty}^{\infty} X(f) e^{j2\pi ft} df$$

### 离散傅里叶变换（DFT）

**正变换：**
$$X[k] = \sum_{n=0}^{N-1} x[n] e^{-j2\pi kn/N}$$

**逆变换：**
$$x[n] = \frac{1}{N} \sum_{k=0}^{N-1} X[k] e^{j2\pi kn/N}$$

### 快速傅里叶变换（FFT）

**问题：** DFT的计算复杂度是 $O(N^2)$，对大信号很慢。

**解决方案：** FFT算法，复杂度降低到 $O(N \log N)$。

**实际应用：** 所有实际系统都用FFT，不用DFT。

## 频谱分析

### 幅度谱（Magnitude Spectrum）

$$|X[k]| = \sqrt{\text{Re}(X[k])^2 + \text{Im}(X[k])^2}$$

**含义：** 每个频率成分的强度。

### 相位谱（Phase Spectrum）

$$\angle X[k] = \arctan\left(\frac{\text{Im}(X[k])}{\text{Re}(X[k])}\right)$$

**含义：** 每个频率成分的相位。

### 功率谱（Power Spectrum）

$$P[k] = |X[k]|^2$$

**含义：** 每个频率成分的功率（能量）。

---

## 重要性质

### 1. 线性性

$$\mathcal{F}(ax + by) = a\mathcal{F}(x) + b\mathcal{F}(y)$$

### 2. 时移性

$$\mathcal{F}(x(t - t_0)) = e^{-j2\pi f t_0} X(f)$$

**含义：** 时间延迟只改变相位，不改变幅度。

### 3. 频移性

$$\mathcal{F}(x(t) e^{j2\pi f_0 t}) = X(f - f_0)$$

**含义：** 乘以复指数相当于频率平移。

### 4. 卷积定理

$$\mathcal{F}(x * h) = \mathcal{F}(x) \cdot \mathcal{F}(h)$$

**含义：** 时域卷积 = 频域乘法。

**应用：** 用FFT快速计算卷积。

---

## 采样定理（Nyquist定理）

### 问题

连续信号如何用离散样本表示？

### 答案

**采样频率必须至少是信号最高频率的2倍。**

$$f_s \geq 2 f_{\max}$$

### 为什么

如果采样频率太低，高频成分会被混叠（aliasing）到低频。

### 例子

```
原始信号：最高频率 10 kHz
采样频率：20 kHz（满足Nyquist定理）
结果：完美重建

采样频率：15 kHz（不满足）
结果：高频成分混叠，无法重建
```

## 实际应用

### 音频处理

- **CD音质**：采样频率44.1 kHz（人耳最高听觉频率约20 kHz）
- **电话**：采样频率8 kHz（人声主要在0-4 kHz）

### 图像处理

- **图像压缩**：用FFT找出重要的频率成分，丢弃不重要的
- **图像增强**：在频域调整，然后逆变换回时域

这里可以把一维傅里叶变换的思想自然推广到二维：对于图像，频率不再只沿时间轴变化，而是沿水平和垂直两个空间方向变化，因此二维傅里叶变换描述的是**空间频率**。进一步地，视频、体数据、阵列观测等更高维信号也可以用同样的思路分解，只是分析的轴从”时间”扩展到了”空间、时间、视角”或其他维度。后续在图像建模、位置编码和多模态模型中，这种”用不同频率描述结构”的思想会反复出现。

### 通信系统

- **调制**：把信息信号转换到高频
- **解调**：从高频信号中提取信息

## 本节小结

傅里叶变换是信号处理的基础：
- 把信号从时域转换到频域
- 揭示信号的频率成分
- 采样定理保证离散采样能完美重建连续信号

## 在LLM中的应用

### 傅里叶变换思想在LLM中的核心应用

傅里叶变换是LLM中位置编码的数学基础：

1. **位置编码的数学原理**
   - 傅里叶变换：用正弦波分解信号
   - 位置编码：用正弦波编码位置
   - 都是用周期函数表示结构信息

2. **Sinusoidal位置编码**
   ```
   PE(pos, 2i) = sin(pos / 10000^(2i/d_model))
   PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))
   ```
   - 直接来自傅里叶变换的思想
   - 用不同频率的正弦波编码不同的位置信息

![Positional Encoding](/assets/ch01_positional_encoding.png)

*图1.2c：Transformer 位置编码矩阵可视化。每一行对应一个位置，每一列对应一个维度，颜色表示编码值。不同频率的正弦/余弦波在不同维度上编码位置信息，与傅里叶变换用不同频率分解信号的思想完全一致。*

**运行方式：** `python code/ch01_dsp/positional_encoding.py`

### 旋转位置编码（RoPE）在LLM中的应用

1. **复数旋转的数学基础**
   - 傅里叶变换使用复指数：$e^{j2\pi ft}$
   - RoPE使用复数旋转编码位置
   - 都是用复数的旋转性质

2. **RoPE的优势**
   - 相对位置编码：自动捕捉相对距离
   - 外推性好：可以处理比训练时更长的序列
   - 在GPT-4、LLaMA等现代LLM中使用

### 频域分析在LLM中的类比

1. **注意力权重 ≈ 频谱**
   - 傅里叶变换：分解信号的频率成分
   - 注意力机制：分解Token之间的关系
   - 都是"分解"和"加权求和"

2. **多头注意力 ≈ 多频率分析**
   - 傅里叶变换：用多个频率分析信号
   - 多头注意力：用多个"注意力头"分析Token关系
   - 都是"多角度"的分析

### 卷积定理在LLM中的应用

1. **时域卷积 = 频域乘法**
   - DSP中的卷积定理：时域卷积可以用频域乘法快速计算
   - LLM中的注意力：可以看作是一种"软卷积"
   - 都是利用变换域的性质加速计算

2. **局部注意力**
   - 类似于DSP中的窗函数
   - 限制注意力范围，提高效率
   - 在长序列LLM中广泛使用

### 采样定理在LLM中的应用

1. **Token采样与信息保留**
   - DSP中的采样定理：采样频率决定了能保留的最高频率
   - LLM中的Token采样：Token数量决定了能保留的最长依赖
   - 都是关于"信息密度"的权衡

2. **上下文窗口的限制**
   - 类似于采样定理的限制
   - 决定了LLM能"看到"的最长范围
   - 现代LLM在扩展上下文窗口（如100K tokens）

### 频率分析在LLM推理中的应用

1. **低频信息 ≈ 全局语义**
   - DSP中的低频：信号的整体趋势
   - LLM中的全局信息：文本的主题和语义
   - 都是"宏观"信息

2. **高频信息 ≈ 局部细节**
   - DSP中的高频：信号的细节变化
   - LLM中的局部信息：词汇和语法细节
   - 都是"微观"信息

3. **多尺度分析**
   - DSP中的小波变换：多尺度分析
   - LLM中的多层Transformer：多层次的特征提取
   - 都是"从粗到细"的分析
