# 1.6 信号检测

**核心问题：** 如何判断信号是否存在？如何在噪声中检测信号？

---

## 检测问题的数学框架

### 问题设置

**观测模型：**
$$y[n] = \begin{cases} w[n] & \text{假设 } H_0 \text{（无信号）} \\ s[n] + w[n] & \text{假设 } H_1 \text{（有信号）} \end{cases}$$

其中：
- $y[n]$：观测信号
- $s[n]$：待检测的信号
- $w[n]$：加性高斯白噪声（AWGN）

### 检测器的任务

**给定观测 $y[n]$，判断：**
- $H_0$：信号不存在（零假设）
- $H_1$：信号存在（备择假设）

**决策规则：**
$$\text{如果 } T(y) > \gamma \text{，则判定 } H_1 \text{；否则判定 } H_0$$

其中 $T(y)$ 是检验统计量，$\gamma$ 是判决阈值。

---

## 假设检验理论

### 两类错误

**第一类错误（假警报，False Alarm）：**
$$P_{fa} = P(\text{判定 } H_1 | H_0 \text{ 真实})$$

含义：信号不存在，但错误地判定为存在。

**第二类错误（漏检，Miss Detection）：**
$$P_{md} = P(\text{判定 } H_0 | H_1 \text{ 真实})$$

含义：信号存在，但错误地判定为不存在。

**检测概率：**
$$P_d = 1 - P_{md} = P(\text{判定 } H_1 | H_1 \text{ 真实})$$

含义：正确检测到信号的概率。

### 权衡关系

**关键观察：** $P_{fa}$ 和 $P_d$ 不能同时很小。

- 降低阈值 $\gamma$ → $P_d$ 增加，$P_{fa}$ 也增加
- 提高阈值 $\gamma$ → $P_{fa}$ 减少，$P_d$ 也减少

**设计目标：** 在给定 $P_{fa}$ 的约束下，最大化 $P_d$。

---

## 似然比检验（Likelihood Ratio Test, LRT）

### 最优检验

**Neyman-Pearson引理：** 最优检验是似然比检验。

$$\Lambda(y) = \frac{p(y|H_1)}{p(y|H_0)} \stackrel{H_1}{\gtrless} \gamma$$

其中 $p(y|H_i)$ 是在假设 $H_i$ 下的似然函数。

### 高斯信号的LRT

**假设：**
- 信号 $s[n]$ 已知
- 噪声是AWGN，方差为 $\sigma^2$

**似然函数：**
$$p(y|H_0) = \prod_{n} \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{y[n]^2}{2\sigma^2}\right)$$

$$p(y|H_1) = \prod_{n} \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(y[n]-s[n])^2}{2\sigma^2}\right)$$

**对数似然比：**
$$\ln \Lambda(y) = \sum_{n} \frac{2y[n]s[n] - s[n]^2}{2\sigma^2}$$

**简化后的检验统计量：**
$$T(y) = \sum_{n} y[n] s[n] \stackrel{H_1}{\gtrless} \gamma$$

**直观理解：** 检验统计量是观测信号与已知信号的相关性。

---

## 接收机工作特性（Receiver Operating Characteristic, ROC）

### ROC曲线

**定义：** 在不同阈值下，$P_d$ 与 $P_{fa}$ 的关系曲线。

**绘制方法：**
1. 改变阈值 $\gamma$
2. 对每个 $\gamma$，计算 $P_d$ 和 $P_{fa}$
3. 绘制 $(P_{fa}, P_d)$ 曲线

### ROC曲线的性质

**完美检测器：**
- 曲线经过点 $(0, 1)$
- 可以同时实现 $P_{fa} = 0$ 和 $P_d = 1$

**随机检测器：**
- 曲线是对角线 $P_d = P_{fa}$
- 检测性能等同于随机猜测

**实际检测器：**
- 曲线在对角线上方
- 越接近左上角，性能越好

![Signal Detection Performance](../../assets/ch01_detection_performance.png)

*图1.6：这组图分成两个层面来展示检测权衡。左图固定检测器与阈值，观察不同 SNR 下检测概率 $P_d$ 和虚警率 $P_{fa}$ 如何变化；右图固定 SNR、扫描不同阈值，得到标准 ROC 曲线。两者合起来说明：阈值决定单点工作位置，而 SNR 决定整条性能曲线能否向左上角移动。*

### 曲线下面积（AUC）

**定义：** ROC曲线下的面积。

$$\text{AUC} = \int_0^1 P_d(P_{fa}) dP_{fa}$$

**性质：**
- AUC = 1：完美检测器
- AUC = 0.5：随机检测器
- AUC越大，检测器越好

---

## 常见检测器

### 1. 能量检测器（Energy Detector）

**适用场景：** 信号未知，只知道噪声功率。

**检验统计量：**
$$T(y) = \sum_{n=0}^{N-1} |y[n]|^2$$

**决策规则：**
$$T(y) \stackrel{H_1}{\gtrless} \gamma$$

**优点：**
- 简单，计算快
- 不需要知道信号形式

**缺点：**
- 性能不如相关检测器
- 对噪声功率估计敏感

### 2. 相关检测器（Correlation Detector）

**适用场景：** 信号已知。

**检验统计量：**
$$T(y) = \sum_{n=0}^{N-1} y[n] s[n]$$

**决策规则：**
$$T(y) \stackrel{H_1}{\gtrless} \gamma$$

**优点：**
- 性能最优（达到Neyman-Pearson界）
- 对已知信号有最高的检测概率

**缺点：**
- 需要精确知道信号

### 3. 匹配滤波器（Matched Filter）

**思想：** 用与信号相匹配的滤波器。这是卷积在检测中的直接应用。

**冲激响应：**
$$h[n] = s[N-1-n]$$

其中 $s[n]$ 是待检测的信号，$N$ 是信号长度。

**输出（卷积运算）：**
$$y_{\text{out}}[n] = \sum_{m=0}^{N-1} y[m] h[n-m] = \sum_{m=0}^{N-1} y[m] s[N-1-n+m]$$

**在 $n = N-1$ 时的输出：**
$$y_{\text{out}}[N-1] = \sum_{m=0}^{N-1} y[m] s[m] = T(y)$$

这正好是相关检测器的统计量！

**与相关检测器的关系：**
- **相关检测器**：直接计算 $T(y) = \sum_{n=0}^{N-1} y[n] s[n]$
- **匹配滤波器**：通过卷积实现相同的功能，在 $n = N-1$ 时输出等于 $T(y)$
- **本质**：两者都是卷积运算，只是实现方式不同

**优点：**
- 最大化信噪比（SNR）— 在所有线性检测器中最优
- 对已知信号最优 — 达到Neyman-Pearson界
- 实现灵活 — 可用硬件或软件实现卷积
- 直观理解 — 滤波器与信号"匹配"程度越高，输出越大

**缺点：**
- 需要精确知道信号形式
- 计算复杂度较高（$O(N^2)$），可用FFT加速到 $O(N\log N)$

**应用场景：**
- 雷达系统：检测已知脉冲信号
- 通信系统：检测已知调制信号
- 声纳系统：检测已知声纳信号
- 医学诊断：检测已知的生物信号模式

---

## 检测性能分析

### 信噪比（Signal-to-Noise Ratio, SNR）

**定义：**
$$\text{SNR} = \frac{P_s}{P_n} = \frac{\sum_{n} s[n]^2}{\sigma^2}$$

其中 $P_s$ 是信号功率，$P_n$ 是噪声功率。

**单位：** dB（分贝）
$$\text{SNR}_{\text{dB}} = 10 \log_{10}(\text{SNR})$$

### 检测性能与SNR的关系

**高斯信号的检测性能：**

对于相关检测器，检验统计量 $T(y)$ 在两个假设下的分布为：

$$T(y) | H_0 \sim \mathcal{N}(0, \sigma^2 \|s\|^2)$$
$$T(y) | H_1 \sim \mathcal{N}(\|s\|^2, \sigma^2 \|s\|^2)$$

**检测概率：**
$$P_d = Q\left(\sqrt{2 \cdot \text{SNR}} - Q^{-1}(P_{fa})\right)$$

其中 $Q(x) = \frac{1}{\sqrt{2\pi}} \int_x^{\infty} e^{-t^2/2} dt$ 是Q函数。

**关键观察：**
- SNR越高，$P_d$ 越高
- 要达到相同的 $P_d$，SNR越高越容易

## 实际应用

### 1. 雷达系统

**问题：** 检测目标是否存在。

**应用：**
- 已知发射信号 → 使用相关检测器
- 计算ROC曲线确定阈值
- 权衡虚警率和漏检率

**例子：**
- 航空管制雷达：虚警率要低（避免误导）
- 防空雷达：漏检率要低（避免漏掉目标）

### 2. 通信系统

**问题：** 检测接收到的信号是否有效。

![Signal Detection](../../assets/ch01_signal_detection.png)

*图1.7：噪声背景下的信号检测示意。检测器通过统计量把“纯噪声”和“信号+噪声”两种情况分开。*

**应用：**
- 信号检测：判断是否收到数据
- 同步检测：检测同步码
- 信道估计：检测导频信号

### 3. 医学诊断

**问题：** 从生物信号中检测异常。

**应用：**
- 心电图（ECG）：检测心律不齐
- 脑电图（EEG）：检测癫痫发作
- 肌电图（EMG）：检测肌肉异常

### 4. 地震学

**问题：** 检测地震波。

**应用：**
- 地震检测：判断是否发生地震
- 震源定位：用多个传感器的检测结果定位
- 地震预警：快速检测和报警

---

## 本节小结

信号检测是信号处理的重要应用：

- **数学框架**：假设检验、似然比检验
- **性能指标**：$P_d$、$P_{fa}$、ROC曲线
- **常见检测器**：能量检测器、相关检测器、匹配滤波器
  - 匹配滤波器是卷积在检测中的应用，达到最优性能
- **性能分析**：SNR与检测性能的关系
- **实际应用**：雷达、通信、医学、地震学

理解这些概念对于设计实际的检测系统至关重要。特别是，匹配滤波器通过卷积运算实现最优检测，是DSP理论与实践的完美结合。

## 在LLM中的应用

### 假设检验在LLM中的应用

1. **二元假设检验 ≈ Token分类**
   - DSP中的假设检验：$H_0$（无信号）vs $H_1$（有信号）
   - LLM中的Token分类：预测下一个Token
   - 都是"二元决策"

2. **多元假设检验 ≈ 多分类**
   - DSP中的多元检测：多个信号中选择一个
   - LLM中的Token预测：从词汇表中选择一个Token
   - 都是"多元决策"

### 似然比检验在LLM中的应用

1. **似然比 ≈ 概率比**
   - DSP中的似然比：$\Lambda = \frac{p(x|H_1)}{p(x|H_0)}$
   - LLM中的概率比：$\frac{P(\text{token}_i)}{P(\text{token}_j)}$
   - 都是"相对概率"

2. **最优检测**
   - DSP中的似然比检验：最优检测器
   - LLM中的Softmax：最优分类器
   - 都是"最优决策"

### 性能指标在LLM中的应用

1. **检测概率 $P_d$ ≈ 准确率**
   - DSP中的$P_d$：正确检测信号的概率
   - LLM中的准确率：正确预测Token的概率
   - 都是"成功率"

2. **虚警概率 $P_{fa}$ ≈ 错误率**
   - DSP中的$P_{fa}$：错误检测信号的概率
   - LLM中的错误率：错误预测Token的概率
   - 都是"失败率"

3. **ROC曲线 ≈ 性能权衡**
   - DSP中的ROC：$P_d$ vs $P_{fa}$的权衡
   - LLM中的精度-召回曲线：精度vs召回的权衡
   - 都是"性能评估"

### 匹配滤波器在LLM中的应用

1. **匹配滤波器的思想**
   - DSP中：用与待检测信号相匹配的滤波器
   - LLM中：用与待预测Token相匹配的注意力权重
   - 都是"最优匹配"

2. **最大化信噪比**
   - DSP中的匹配滤波器：最大化SNR
   - LLM中的注意力：最大化相关Token的权重
   - 都是"信号增强"

3. **卷积实现**
   - DSP中的匹配滤波器：通过卷积实现
   - LLM中的注意力：可以看作是一种"软卷积"
   - 都是"卷积运算"

### 能量检测器在LLM中的应用

1. **能量检测**
   - DSP中的能量检测器：检测信号的能量
   - LLM中的置信度：Token预测的置信度
   - 都是"能量/强度"

2. **阈值设置**
   - DSP中的能量检测：设置能量阈值
   - LLM中的采样：设置温度参数
   - 都是"阈值决策"

### 相关检测器在LLM中的应用

1. **相关性**
   - DSP中的相关检测器：计算信号与模板的相关性
   - LLM中的注意力：计算Token之间的相关性
   - 都是"相关性度量"

2. **最优匹配**
   - DSP中的相关检测器：找到最相关的模板
   - LLM中的注意力：找到最相关的Token
   - 都是"最优匹配"

### 信噪比与性能的关系在LLM中的应用

1. **SNR与检测性能**
   - DSP中：SNR越高，检测性能越好
   - LLM中：Token的置信度越高，预测越准确
   - 都是"质量指标"

2. **性能曲线**
   - DSP中的$P_d$-SNR曲线：检测性能随SNR变化
   - LLM中的准确率-置信度曲线：准确率随置信度变化
   - 都是"性能分析"

### 检测在LLM推理中的应用

1. **Token检测**
   - 类似于DSP中的信号检测
   - 判断某个Token是否应该出现
   - 用于生成控制和质量评估

2. **异常检测**
   - 类似于DSP中的异常信号检测
   - 检测生成文本中的异常Token
   - 用于内容安全和质量控制
