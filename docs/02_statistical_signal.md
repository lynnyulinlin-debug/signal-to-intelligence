# 第2章：统计信号处理

## 导读

上一章我们学会了"看"信号（傅里叶变换）和"过滤"信号（滤波器）。这一章回答一个更深层的问题：**在有噪声的情况下，怎样从观测数据中推断出真实的信号？** 这就是统计信号处理的核心——估计和检测。你会发现，神经网络的损失函数（MSE、交叉熵）其实就是统计学中的最小均方误差（MMSE）和最大似然估计（MLE）的现代版本。

## 2.1 从确定性到概率性

### 直觉类比

在DSP中，我们假设信号是确定的。但现实中，观测总是有噪声的。

想象你在嘈杂的房间里听别人说话。你听到的不是"确定的"声音，而是"真实声音 + 背景噪声"的混合。你的大脑要做的是：**从混合信号中推断出最可能的真实声音**。

这就是从确定性到概率性的转变。

### 数值示例

假设真实信号是 $x = 5$，但你的观测是 $y = 5 + \text{噪声}$。

```
观测1: y = 4.8
观测2: y = 5.2
观测3: y = 5.1
```

你怎么估计真实的 $x$？最直观的方法是取平均：$\hat{x} = (4.8 + 5.2 + 5.1) / 3 = 5.03$。

但如果你知道"噪声的方差很大"，你可能会给最近的观测更高的权重。这就是**加权平均**，也是MMSE的思想。

### 核心公式

**最小均方误差（MMSE）估计：**

$$\hat{x} = \frac{\sigma_x^2}{\sigma_x^2 + \sigma_n^2} \cdot y$$

**人话解释：** 估计值是观测值的加权平均。权重取决于"信号方差"和"噪声方差"的比例。信号越强（方差大），权重越接近1；噪声越强，权重越接近0。

### 代码验证

```python
import numpy as np

# 参数
signal_var = 1.0
noise_var = 0.5
y = 5.0  # 观测值

# MMSE估计
mmse_gain = signal_var / (signal_var + noise_var)
x_hat = mmse_gain * y

print(f"MMSE增益: {mmse_gain:.4f}")
print(f"估计值: {x_hat:.4f}")
# 输出：MMSE增益: 0.6667, 估计值: 3.3333
```

## 2.2 最大似然估计（MLE）

### 直觉类比

MMSE假设你知道信号和噪声的统计特性。但如果你不知道呢？

最大似然估计（MLE）的思想是：**选择最能解释观测数据的参数**。

想象你看到一个骰子连续掷出6次6点。你会怀疑这个骰子是不是被做过手脚（概率不是1/6）。MLE就是找到"最可能产生这个观测结果"的参数。

### 数值示例

假设你有观测数据：$y = [4.8, 5.2, 5.1]$，你想估计真实值 $x$。

如果假设噪声是高斯分布，那么观测的概率是：

$$P(y | x) = \prod_{i} \frac{1}{\sqrt{2\pi\sigma_n^2}} \exp\left(-\frac{(y_i - x)^2}{2\sigma_n^2}\right)$$

最大化这个概率，你会得到 $x = \text{mean}(y) = 5.03$。

### 核心公式

**最大似然估计（对于高斯噪声）：**

$$\hat{x}_{MLE} = \arg\max_x \sum_i \log P(y_i | x) = \arg\min_x \sum_i (y_i - x)^2$$

**人话解释：** 最大化似然等价于最小化平方误差。这就是为什么神经网络用MSE损失函数——它就是MLE！

## 2.3 从统计学到神经网络

### 概念对照表

| 统计信号处理 | 神经网络 | 关键差异 |
|-------------|---------|---------|
| MMSE估计（已知统计特性） | 回归（学习参数） | 从固定公式→可学习模型 |
| MLE（最大似然） | MSE损失函数 | 同一个东西，不同的名字 |
| 贝叶斯估计（融合先验） | 正则化（权重衰减） | 都在"数据"和"先验"之间平衡 |

### 反直觉点拨

**常见误解：** "神经网络和统计学是两个不同的领域"

**正确理解：** 神经网络就是统计学的参数化版本。当你训练一个神经网络最小化MSE损失时，你实际上在做最大似然估计。当你加入L2正则化时，你在做贝叶斯推断。

**常见误解：** "深度学习不需要理解统计学"

**正确理解：** 理解统计学能帮你更好地设计损失函数、选择正则化方法、理解为什么某些训练技巧有效。

### 代码对比

**传统统计学：MMSE**
```python
# 已知信号和噪声的方差
signal_var = 1.0
noise_var = 0.5
y = 5.0

mmse_gain = signal_var / (signal_var + noise_var)
x_hat = mmse_gain * y
```

**现代AI：神经网络**
```python
import torch
import torch.nn as nn

# 神经网络自动学习"增益"
model = nn.Linear(1, 1)
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)

y_tensor = torch.tensor([[5.0]])
x_true = torch.tensor([[3.33]])

for _ in range(100):
    y_pred = model(y_tensor)
    loss = (y_pred - x_true) ** 2
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

# 学到的权重接近MMSE增益
print(f"学到的权重: {model.weight.item():.4f}")
```

## 2.4 检测：二分类的统计基础

### 直觉类比

估计是"推断一个连续的值"。检测是"判断一个二元的选择"。

想象你在医院做检测：阳性还是阴性？你的检测结果不是100%准确的，所以医生要权衡"假阳性"（健康人被诊断为患病）和"假阴性"（患病人被诊断为健康）的风险。

### 数值示例

假设你要判断一个信号是"有目标"还是"无目标"。

```
假设：
- 有目标时，观测值通常 > 0.5
- 无目标时，观测值通常 < -0.5
- 观测值 = 0.2

你的判断：无目标（因为0.2更接近无目标的分布）
```

### 核心公式

**似然比检测：**

$$\frac{P(y | H_1)}{P(y | H_0)} \stackrel{?}{>} \tau$$

**人话解释：** 计算"在假设1下观测到y的概率"与"在假设0下观测到y的概率"的比值。如果比值大于阈值 $\tau$，选择假设1；否则选择假设0。

## 2.5 本章小结

**核心要点：**

1. **从确定性到概率性** — 现实中有噪声，所以我们需要概率模型。MMSE和MLE是两种经典的估计方法。

2. **统计学和神经网络是同一件事** — MSE损失函数就是MLE，正则化就是贝叶斯先验。理解统计学能帮你更好地理解深度学习。

3. **从固定公式到可学习参数** — 统计学给出了"最优"的公式（如MMSE增益），但需要知道参数。神经网络让这些参数自动学习。
