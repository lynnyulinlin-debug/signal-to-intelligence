# 5.4 Prompt工程基础

**核心问题：** 如何写好Prompt来充分利用LLM的能力？

---

## Prompt的结构

### 基本结构

```
[背景信息]
[任务描述]
[示例（可选）]
[输入]
```

### 例子

```
你是一个专业的翻译。

将以下英文翻译成中文：

示例：
- "Hello" → "你好"
- "Good morning" → "早上好"

现在翻译："Good night"
```

---

## Prompt设计的原则

### 1. 清晰明确

**不好：** "翻译这个"
**好：** "将以下英文翻译成中文，保持原意"

### 2. 提供上下文

**不好：** "这是什么？"
**好：** "这是一个关于机器学习的论文摘要。请总结主要贡献。"

### 3. 给出示例

**不好：** "分类这些句子"
**好：** 
```
分类以下句子为正面或负面情感：

示例：
- "很好用" → 正面
- "不好用" → 负面

现在分类："一般般"
```

### 4. 指定输出格式

**不好：** "生成一个故事"
**好：** "生成一个100字以内的故事，格式为：标题\n内容"

---

## 高级技巧

### Chain-of-Thought

让模型一步步推理，而不是直接输出答案。

```
问题：15 + 27 = ?

不好的Prompt：
"15 + 27 = ?"

好的Prompt：
"让我一步步计算：
15 + 27
= 15 + 20 + 7
= 35 + 7
= 42"
```

### 角色扮演

让模型扮演特定角色。

```
你是一个资深的Python工程师。
请审查以下代码并给出改进建议。
```

---

## 本节小结

Prompt工程的关键：
- 清晰明确的任务描述
- 提供充分的上下文
- 给出示例
- 指定输出格式
