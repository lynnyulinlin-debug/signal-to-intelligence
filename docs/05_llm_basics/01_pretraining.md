# 5.1 预训练思想

**核心问题：** 什么是预训练？为什么它这么重要？

---

## 传统监督学习的问题

### 问题1：需要大量标注数据

```
任务1：需要10万条标注数据
任务2：需要10万条标注数据
任务3：需要10万条标注数据
...
```

标注数据很贵，很难获得。

### 问题2：难以迁移

在任务1上训练的模型，在任务2上效果很差。

---

## 预训练的思想

### 核心思想

用海量无标注数据预训练一个通用模型，然后在下游任务上微调。

```
海量无标注数据
  ↓
预训练（学习通用语言理解）
  ↓
微调（适应特定任务）
  ↓
下游任务
```

### 为什么有效

预训练学到的是通用的语言理解能力，可以迁移到任何下游任务。

---

## 预训练任务

### 语言模型（Language Modeling）

**任务：** 给定前面的单词，预测下一个单词。

$$P(w_t | w_1, ..., w_{t-1})$$

**优点：** 
- 无需标注数据
- 自动学习语言结构

### 掩码语言模型（Masked Language Modeling）

**任务：** 给定上下文，预测被掩码的单词。

```
输入：The [MASK] sat on the mat
目标：cat
```

**优点：** 
- 学习双向上下文
- BERT使用这个任务

---

## 预训练的效果

### 数据量的影响

```

  |     /
  |    /
  |   /
  |  /
  | /
  |/___________
```

更多数据 → 更好的性能。

### 模型大小的影响

```
模型大小 → 模型性能
  |     /
  |    /
  |   /
  |  /
  | /
  |/___________
```

更大的模型 → 更好的性能。

---

## 本节小结

预训练用海量无标注数据学习通用语言理解，然后微调到下游任务。
