# 5.2 Scaling Laws

**核心问题：** 模型大小、数据量、计算量如何影响性能？

---

## Scaling Laws的发现

### 关键发现

模型性能与模型大小、数据量、计算量的关系遵循幂律。

$$L(N) = aN^{-\alpha}$$

其中：
- $L$：损失函数
- $N$：参数数量
- $\alpha$：幂律指数（约0.07）

### 含义

**性能随参数量单调增长，没有饱和点。**

```
性能
  |     /
  |    /
  |   /
  |  /
  | /
  |/___________
  参数量
```

---

## 三个维度的权衡

### 模型大小 vs 数据量

**问题：** 给定计算预算，应该用大模型+少数据，还是小模型+多数据？

**答案：** 应该平衡两者。

**Chinchilla缩放律：**
- 计算量应该平均分配给模型大小和数据量
- 最优的数据量 ≈ 20倍的参数量

### 例子

```
GPT-3：175B参数，300B tokens
Chinchilla：70B参数，1.4T tokens

Chinchilla用更少的参数，但更多的数据，性能相当。
```

---

## 涌现能力（Emergent Abilities）

### 定义

当模型大小达到一定规模时，突然出现之前没有的能力。

### 例子

**In-Context Learning：**
- 小模型：无法从示例中学习
- 大模型：看几个例子就能完成新任务

**Chain-of-Thought：**
- 小模型：直接输出答案，错误率高
- 大模型：一步步推理，准确率大幅提升

---

## 本节小结

Scaling Laws表明：
- 性能随参数量单调增长
- 应该平衡模型大小和数据量
- 大模型会涌现新能力
