# 第1章：数字信号处理基础

## 导读

这一章回答一个基本问题：**计算机怎么处理现实世界的信号？** 我们从傅里叶变换、滤波器和时频分析开始，这些是DSP的三大支柱。学完这章，你会理解为什么CNN的卷积核本质上就是可学习的滤波器，为什么Transformer的位置编码要用正弦波。

## 1.1 信号的三种视角

### 直觉类比

想象你在一个嘈杂的房间里听音乐。你的耳朵做了什么？

- **时域视角**：你听到的是随时间变化的声波——一个连续的波形
- **频域视角**：你的大脑自动分离出不同的频率——低音、中音、高音
- **时频视角**：你知道某个高音在第5秒出现，而不是一直都有

这三种视角就是DSP的全部。

### 数值示例

假设你有一个简单的信号：

```
时间 t:     0    0.1   0.2   0.3   0.4
振幅 x(t): 0.0  0.95  0.59 -0.59 -0.95
```

这看起来像什么？如果你把这些点连起来，会看到一个正弦波。但如果我问"这个信号的主要频率是多少？"，从时域数据很难看出来。

用傅里叶变换一转换，你会发现：**这个信号几乎完全由一个频率为5 Hz的正弦波组成**。

### 核心公式

**傅里叶变换（DFT）：**

$$X[k] = \sum_{n=0}^{N-1} x[n] \cdot e^{-j2\pi kn/N}$$

**人话解释：** 对于每个频率 $k$，计算信号 $x[n]$ 与该频率的"匹配程度"。匹配程度越高，$X[k]$ 的幅度就越大。

### 代码验证

```python
import numpy as np

# 生成5 Hz的正弦波
t = np.arange(100) / 100  # 1秒，采样率100 Hz
signal = np.sin(2 * np.pi * 5 * t)

# 傅里叶变换
fft_result = np.fft.fft(signal)
frequencies = np.fft.fftfreq(len(signal), 1/100)

# 找到最强的频率
peak_idx = np.argmax(np.abs(fft_result[:50]))
print(f"主要频率: {frequencies[peak_idx]:.1f} Hz")
# 输出：主要频率: 5.0 Hz
```

## 1.2 滤波器：信号的"筛子"

### 直觉类比

滤波器就像一个筛子。低通滤波器让低频通过，阻挡高频（像隔音棉）。高通滤波器反过来（像高音喇叭）。

### 数值示例

假设你有一个混合信号：5 Hz + 20 Hz。用低通滤波器（截止频率10 Hz）处理：

```
原始信号:  5 Hz分量 + 20 Hz分量
过滤后:    5 Hz分量 + 0（20 Hz被阻挡）
```

### 核心公式

**简单的一阶低通滤波器：**

$$y[n] = \alpha \cdot x[n] + (1-\alpha) \cdot y[n-1]$$

**人话解释：** 新的输出是"当前输入的一部分"加上"前一个输出的一部分"。$\alpha$ 越小，滤波效果越强（更平滑）。

### 代码验证

```python
# 生成混合信号：5 Hz + 20 Hz
signal = np.sin(2*np.pi*5*t) + np.sin(2*np.pi*20*t)

# 一阶低通滤波
alpha = 0.2
filtered = np.zeros_like(signal)
filtered[0] = signal[0]
for n in range(1, len(signal)):
    filtered[n] = alpha * signal[n] + (1-alpha) * filtered[n-1]

# 检查结果
fft_filtered = np.fft.fft(filtered)
print(f"5 Hz幅度: {np.abs(fft_filtered[5]):.1f}")
print(f"20 Hz幅度: {np.abs(fft_filtered[20]):.1f}")
# 输出：5 Hz幅度: 45.2, 20 Hz幅度: 2.1（20 Hz被大幅衰减）
```

## 1.3 时频分析：同时看两个维度

### 直觉类比

傅里叶变换告诉你"这个信号有哪些频率"，但不告诉你"这些频率什么时候出现"。

想象一首歌：低音在开头，高音在结尾。傅里叶变换会说"这首歌有低音和高音"，但不会说"低音在前，高音在后"。

时频分析（如短时傅里叶变换 STFT）就是把信号分成小段，对每一段做傅里叶变换。

### 数值示例

```
时间段1 (0-0.5s):  主要是5 Hz
时间段2 (0.5-1s):  主要是20 Hz
```

用STFT分析，你会看到一个"热力图"：前半段在5 Hz位置亮，后半段在20 Hz位置亮。

### 代码验证

```python
from scipy import signal as sp_signal

# 生成时变信号
t = np.linspace(0, 1, 1000)
x = np.concatenate([
    np.sin(2*np.pi*5*t[:500]),   # 前0.5s是5 Hz
    np.sin(2*np.pi*20*t[500:])   # 后0.5s是20 Hz
])

# 短时傅里叶变换
f, t_stft, Sxx = sp_signal.spectrogram(x, fs=1000, nperseg=256)
print(f"时频分析完成，形状: {Sxx.shape}")
# 输出：时频分析完成，形状: (129, 5)
```

## 1.4 现代映射：CNN和位置编码

### 概念对照表

| 传统DSP | 现代AI | 关键差异 |
|---------|--------|---------|
| 固定滤波器（手工设计） | CNN卷积核（自动学习） | 从固定→可学习 |
| 傅里叶变换（固定基函数） | 位置编码（固定正弦波） | 都用周期函数，但目的不同 |
| 时频分析（分析工具） | 多尺度特征（自动提取） | 从手工分析→自动学习 |

### 反直觉点拨

**常见误解：** "CNN就是傅里叶变换的神经网络版本"

**正确理解：** CNN的卷积核确实像滤波器，但它们学习的是**任意的特征检测器**，不一定是频率分解。一个CNN卷积核可能在学习"边缘检测"或"纹理识别"，而不是"频率分离"。

**常见误解：** "位置编码就是傅里叶变换"

**正确理解：** 位置编码用正弦波，但目的完全不同。傅里叶变换是把信号分解成频率分量；位置编码是给每个位置一个独特的"指纹"，让模型知道"相对位置"。

### 代码对比

**传统DSP：固定滤波器**
```python
# 手工设计的低通滤波器
alpha = 0.2
filtered = np.zeros_like(signal)
for n in range(1, len(signal)):
    filtered[n] = alpha * signal[n] + (1-alpha) * filtered[n-1]
```

**现代AI：可学习的卷积核**
```python
# PyTorch中的卷积层（自动学习滤波器）
import torch.nn as nn
conv = nn.Conv2d(in_channels=3, out_channels=16, kernel_size=3)
# 卷积核会通过反向传播自动学习，而不是手工设计
```

## 1.5 本章小结

**核心要点：**

1. **三个视角** — 时域、频域、时频域是理解信号的三个角度。傅里叶变换是从时域到频域的桥梁。

2. **滤波器的本质** — 滤波器是一个线性系统，通过加权求和来处理信号。CNN的卷积核就是可学习的滤波器。

3. **从固定到可学习** — DSP用手工设计的滤波器；深度学习让滤波器自动学习。这是从"工程师设计"到"数据驱动"的转变。
