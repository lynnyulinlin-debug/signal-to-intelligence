# 第7章：Transformer与自注意力

## 导读

前六章我们学会了"看"信号、"推断"信号、"优化"参数、"跟踪"系统、"权衡"复杂度、"学习"特征。这一章回答一个关键问题：**怎样处理长序列，同时捕捉远距离的依赖关系？** RNN有梯度消失问题，卷积的感受野有限。Transformer通过自注意力机制解决了这个问题。更重要的是，自注意力本质上就是"软对齐"——一个序列中的每个位置都能"看到"其他所有位置，并根据相关性加权。

## 7.1 注意力机制：软对齐

### 直觉类比

想象你在读一篇文章。当你读到"它"这个代词时，你需要回顾前面的文本，找到"它"指代的是什么。

注意力机制就是这个过程：**对于当前位置，计算它与所有其他位置的相关性，然后加权求和**。

### 数值示例

```
句子：The cat sat on the mat
当前词：sat

注意力权重：
  The: 0.1
  cat: 0.7（最相关）
  sat: 0.1
  on: 0.05
  the: 0.03
  mat: 0.02

输出 = 0.1*The_vec + 0.7*cat_vec + 0.1*sat_vec + ...
```

### 核心公式

**缩放点积注意力：**

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

**人话解释：** 
- Q（查询）：当前位置想问什么
- K（钥匙）：其他位置能提供什么
- V（值）：其他位置的信息
- 计算Q和K的相似度，用softmax转换成权重，加权求和V

## 7.2 多头注意力

### 直觉类比

一个人的注意力有限。多头注意力就像让多个人同时看同一个问题，每个人关注不同的方面。

### 数值示例

```
头1：关注语法关系
  The → cat: 0.8
  cat → sat: 0.7

头2：关注语义关系
  cat → mat: 0.6
  sat → on: 0.5

头3：关注距离关系
  sat → The: 0.3
  sat → mat: 0.4
```

### 核心公式

**多头注意力：**

$$\text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, ..., \text{head}_h)W^O$$

其中 $\text{head}_i = \text{Attention}(QW_i^Q, KW_i^K, VW_i^V)$

**人话解释：** 把Q、K、V分成多个"头"，每个头独立计算注意力，然后拼接。

## 7.3 位置编码

### 直觉类比

Transformer没有循环结构，所以需要显式地告诉模型"位置信息"。位置编码就是给每个位置一个独特的"指纹"。

### 数值示例

```
位置0: [sin(0), cos(0), sin(0), cos(0), ...]
位置1: [sin(1), cos(1), sin(1/100), cos(1/100), ...]
位置2: [sin(2), cos(2), sin(2/100), cos(2/100), ...]
```

### 核心公式

**正弦位置编码：**

$$PE(pos, 2i) = \sin\left(\frac{pos}{10000^{2i/d}}\right)$$
$$PE(pos, 2i+1) = \cos\left(\frac{pos}{10000^{2i/d}}\right)$$

**人话解释：** 用不同频率的正弦和余弦波编码位置。高频分量捕捉相对位置，低频分量捕捉绝对位置。

## 7.4 从RNN到Transformer

### 概念对照表

| RNN | Transformer | 关键差异 |
|-----|-------------|---------|
| 顺序处理 | 并行处理 | 从顺序→并行 |
| 隐状态 | 注意力权重 | 从隐式→显式 |
| 梯度消失 | 直接连接 | 从长距离困难→容易 |

### 反直觉点拨

**常见误解：** "Transformer完全替代了RNN"

**正确理解：** Transformer在长序列上更好，但RNN在某些场景（如流式处理、固定长度序列）仍然有用。

**常见误解：** "自注意力就是计算所有位置对之间的相似度"

**正确理解：** 自注意力是**学习得到的**相似度。模型通过训练学会"什么时候应该关注什么"。

## 7.5 本章小结

**核心要点：**

1. **注意力是软对齐** — 从硬的对齐（RNN的顺序处理）到软的对齐（Transformer的加权求和）。

2. **多头注意力捕捉多个方面** — 不同的头学到不同的注意力模式。

3. **位置编码保留位置信息** — 虽然Transformer是并行的，但通过位置编码保留了位置信息。
