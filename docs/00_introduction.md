# 第0章：导论

## 一句话定位

这份教程帮助你把已有的信号处理/统计知识迁移到现代AI（深度学习、大模型、多模态）的理解中——不重复造轮子，而是看清楚"从DSP到Transformer"的思想演化路线。

## 你为什么要读这个

如果你曾经问过自己这些问题，这份教程就是为你写的：

- "Transformer 是怎么来的？为什么要用自注意力？"
- "Mamba 和卡尔曼滤波有什么关系？"
- "CNN 不就是一个可学习的滤波器组吗？"
- "RNN 的隐状态和卡尔曼滤波的状态有什么区别？"
- "为什么位置编码要用正弦波？"

这些问题的答案都指向同一个事实：**现代AI不是凭空产生的，而是从信号处理的基本原则中一步步生长出来的**。

## 目标读者

- 具有本科/硕士理工科背景，工作1~5年的工程师
- 学过至少一门：数字信号处理、通信、自动化、控制、计算机视觉或机器学习基础
- 不想读大部头教材，也不想只看概念幻灯片，希望有代码跑起来验证想法

## 前置知识（最低要求）

- 会用 Python + NumPy（或愿意边学边用）
- 知道什么是向量、矩阵、导数、概率
- 听说过傅里叶变换、卷积、梯度下降

**如果你对某些概念不熟，不用担心——每章都会从基础开始，用"三步拆解"的方式讲解。**

## 全书的故事线

智能的演化可以看作一条清晰的思想链条：

```
数字信号处理（DSP）
    ↓ 特征提取方式
统计信号处理（估计与检测）
    ↓ 处理不确定性
自适应滤波 / 卡尔曼滤波
    ↓ 从解析解走向迭代优化
机器学习（浅层）
    ↓ 自动特征学习
深度学习（CNN / RNN）
    ↓ 处理长距离依赖
Transformer（自注意力）
    ↓ 统一序列建模
ViT / 多模态（视觉 + 语言）
    ↓ 信息融合
（未来展望：具身智能 / 科学AI）
```

每一步都不是凭空出现的——都是前一步的自然延伸。

## 每章的结构

每章都遵循同样的模式：

### 导读（150字以内）
- 本章解决什么问题
- 与前一章的关系
- 学完后能做什么

### 传统思想
- **直觉类比**：用生活场景描述，不写公式
- **数值示例**：具体的小数字演示
- **核心公式**：最多2个公式，每个下面一句话解释
- **代码验证**：≤15行核心代码

### 现代映射
- **概念对照表**：传统 vs 现代的映射
- **反直觉点拨**：常见误解 vs 正确理解
- **代码对比**：传统代码 vs 现代代码

### 本章小结
- 3个核心要点
- 推荐阅读
- 实验代码位置

## 代码实验的原则

每章都有最小可运行的代码实验：

- **独立性** — 每个实验可单独运行：`python code/chN_xxx/experiment.py`
- **最小化** — 核心逻辑 ≤ 30 行（不含 import、绘图、注释）
- **可复现** — 固定随机种子，输出确定
- **合成数据** — 除非必要，不用真实大数据集
- **清晰输出** — 打印数值结果 + 可选绘图

## 常见问题

**Q: 我没有信号处理背景，能读吗？**

A: 可以。第1-4章会从零开始讲解DSP概念。如果某个地方卡住了，查看对应的代码实验——代码往往比文字更清楚。

**Q: 我没有深度学习背景，能读吗？**

A: 可以。第5-8章会从浅层模型开始，逐步引入深度学习。每个概念都有代码验证。

**Q: 这个教程能替代大学课程吗？**

A: 不能。这是一份"思想对照式"的快速入门，目标是帮你看清楚"从DSP到AI"的演化链条。如果你需要深入学习某个领域，还是要读专业教材。

**Q: 代码用的是什么框架？**

A: 第1-5章主要用 NumPy（轻量）。第6-8章可选用 PyTorch（标记为"扩展"）。

**Q: 我可以跳过某些章节吗？**

A: 可以，但建议按顺序读。每章都为后面的章节铺垫。如果你只对某个话题感兴趣，查看"路径指引"部分。
