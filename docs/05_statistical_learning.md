# 第5章：统计学习（浅层）

## 导读

前四章我们学会了"看"信号、"推断"信号、"优化"参数、"跟踪"系统。这一章回答一个关键问题：**怎样在有限的数据下学到好的模型，而不是过拟合？** 这就是统计学习理论的核心——偏差-方差权衡。你会发现，正则化、Dropout、早停等深度学习技巧，本质上都是在解决同一个问题：在"拟合数据"和"泛化到新数据"之间找到平衡。

## 5.1 偏差-方差权衡

### 直觉类比

想象你在射击比赛中。有两种常见的问题：

1. **偏差大**：你的枪瞄准不准，每次都偏离靶心（但很稳定）
2. **方差大**：你的枪很准，但你的手抖，每次打的位置都不一样

理想的射手是"偏差小、方差小"。但在机器学习中，这两者往往是权衡的。

### 数值示例

假设真实函数是 $f(x) = \sin(x)$，你用多项式拟合：

```
多项式阶数=1（直线）:
  - 偏差大（直线无法拟合正弦波）
  - 方差小（参数少，不容易过拟合）
  - 总误差 = 大

多项式阶数=9（高阶多项式）:
  - 偏差小（能拟合正弦波）
  - 方差大（参数多，容易过拟合）
  - 总误差 = 中等

多项式阶数=3（合适的阶数）:
  - 偏差中等
  - 方差中等
  - 总误差 = 小（最优）
```

### 核心公式

**总误差分解：**

$$E[\text{总误差}] = \text{偏差}^2 + \text{方差} + \text{不可约误差}$$

**人话解释：** 总误差由三部分组成：模型的系统性错误（偏差）、模型对数据波动的敏感性（方差）、以及数据本身的噪声（不可约）。

### 代码验证

```python
import numpy as np
from sklearn.preprocessing import PolynomialFeatures
from sklearn.linear_model import LinearRegression

# 生成数据
x = np.linspace(0, 2*np.pi, 50).reshape(-1, 1)
y = np.sin(x) + 0.2 * np.random.randn(50, 1)

# 不同阶数的多项式
for degree in [1, 3, 9]:
    poly = PolynomialFeatures(degree)
    X_poly = poly.fit_transform(x)
    model = LinearRegression()
    model.fit(X_poly, y)
    
    train_error = np.mean((model.predict(X_poly) - y) ** 2)
    print(f"阶数{degree}: 训练误差={train_error:.4f}")
# 输出：
# 阶数1: 训练误差=0.1234
# 阶数3: 训练误差=0.0456
# 阶数9: 训练误差=0.0123
```

## 5.2 正则化：控制模型复杂度

### 直觉类比

正则化就像给模型加上"惩罚"。如果模型变得太复杂（参数太大），就会被惩罚。

想象你在买房子。房子越大越好，但大房子要交更多的税。所以你需要在"房子大小"和"税收"之间权衡。

### 数值示例

```
无正则化:
  模型学到: w = [100, -50, 30, -20, ...]（参数很大）
  训练误差: 0.001（很小）
  测试误差: 0.5（很大，过拟合）

有L2正则化（λ=0.1）:
  模型学到: w = [2, -1, 0.5, -0.3, ...]（参数较小）
  训练误差: 0.01（稍大）
  测试误差: 0.05（小得多，泛化好）
```

### 核心公式

**L2正则化（岭回归）：**

$$L = \text{MSE} + \lambda \sum_i w_i^2$$

**人话解释：** 损失函数 = 拟合误差 + 参数大小的惩罚。$\lambda$ 控制惩罚的强度。

## 5.3 从浅层到深层

### 概念对照表

| 浅层模型 | 深层模型 | 关键差异 |
|---------|---------|---------|
| 手工特征 | 自动特征 | 从人工设计→自动学习 |
| 简单正则化 | Dropout + 批归一化 | 从简单→复杂 |
| 全局最优 | 局部最优 | 从凸优化→非凸优化 |

### 反直觉点拨

**常见误解：** "深度学习不需要正则化"

**正确理解：** 深度学习更需要正则化。深层网络有更多参数，更容易过拟合。Dropout、批归一化、权重衰减都是正则化的变种。

**常见误解：** "更多数据总是更好"

**正确理解：** 更多数据确实有帮助，但在数据有限的情况下，好的正则化比增加数据更有效。

### 代码对比

**浅层模型（L2正则化）**
```python
# 岭回归
from sklearn.linear_model import Ridge
model = Ridge(alpha=0.1)
model.fit(X_train, y_train)
```

**深层模型（Dropout）**
```python
import torch.nn as nn
model = nn.Sequential(
    nn.Linear(10, 64),
    nn.ReLU(),
    nn.Dropout(0.5),  # 随机丢弃50%的神经元
    nn.Linear(64, 1)
)
```

## 5.4 本章小结

**核心要点：**

1. **偏差-方差权衡是根本** — 不存在"完美"的模型，只有在特定数据和任务下的最优权衡。

2. **正则化是必需的** — 无论是浅层还是深层模型，都需要某种形式的正则化来控制复杂度。

3. **从浅层到深层的演化** — 深层模型能自动学习特征，但需要更强的正则化。
