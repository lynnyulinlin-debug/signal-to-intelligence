# 6.4 实战案例

**核心问题：** 如何把这些技术结合起来？

---

## 案例1：客服机器人

### 需求

回答客户的问题，可能需要查询订单或政策。

### 解决方案

```
用户问题
  ↓
RAG检索相关政策
  ↓
Agent调用查询订单工具
  ↓
LLM生成回答
```

### 技术栈

- RAG：检索政策文档
- Agent：调用订单查询工具
- 提示工程：定义回答风格

---

## 案例2：数据分析助手

### 需求

用户提问，系统自动分析数据并生成报告。

### 解决方案

```
用户问题
  ↓
Agent调用数据查询工具
  ↓
Agent调用数据分析工具
  ↓
LLM生成报告
```

### 技术栈

- Agent：调用多个工具
- 微调：定制报告格式

---

## 案例3：代码生成助手

### 需求

根据需求生成代码。

### 解决方案

```
用户需求
  ↓
RAG检索相关代码示例
  ↓
LLM生成代码
  ↓
Agent调用代码检查工具
```

### 技术栈

- RAG：检索代码示例
- 提示工程：定义代码风格
- Agent：调用代码检查工具

---

## 本节小结

结合RAG、Agent、微调和提示工程，可以构建强大的LLM应用。
