## 关键概念速查

| 技术 | 适用场景 | 优点 | 缺点 |
|------|---------|------|------|
| 微调 | 特定领域任务 | 性能好 | 需要标注数据、成本高 |
| 提示工程 | 通用任务 | 快速、低成本 | 性能可能不如微调 |
| RAG | 需要外部知识 | 知识可更新 | 检索质量影响效果 |
| Agent | 复杂任务 | 灵活、可规划 | 实现复杂、成本高 |

## 常见问题

**Q: 什么时候应该微调，什么时候应该用提示工程？**
A: 如果有足够的标注数据且性能要求高，用微调。否则先尝试提示工程。

**Q: RAG相比微调有什么优势？**
A: RAG的知识可以实时更新，不需要重新训练模型。适合知识频繁变化的场景。

**Q: Agent框架如何工作？**
A: Agent通过LLM的推理能力，决定调用哪些工具、如何组合结果，实现复杂的多步任务。

**Q: 如何评估LLM应用的质量？**
A: 根据任务类型选择合适的指标（准确率、BLEU、人工评估等），并进行A/B测试。
