# 6.4 Agent 框架

**核心问题：** 如何让LLM能调用工具和规划？

---

## 问题

LLM只能生成文本，无法调用工具或执行复杂任务。

**例子：**
- 查询数据库
- 调用API
- 执行计算

---

## Agent的思想

### 核心思想

让LLM决定调用哪个工具，然后执行工具，再继续推理。

```
用户问题
  ↓
LLM决定调用哪个工具
  ↓
执行工具
  ↓
LLM根据工具结果继续推理
  ↓
重复直到完成
```

---

## Agent的步骤

### 1. 定义工具

```python
tools = [
    {
        "name": "search",
        "description": "搜索网络",
        "parameters": {...}
    },
    {
        "name": "calculator",
        "description": "计算数学表达式",
        "parameters": {...}
    }
]
```

### 2. LLM选择工具

LLM根据问题选择合适的工具。

### 3. 执行工具

执行LLM选择的工具。

### 4. 反馈给LLM

把工具结果反馈给LLM，继续推理。

---

## 本节小结

Agent让LLM能调用工具和规划，完成复杂任务。
