# 第6章：深度学习（表示学习）

## 导读

前五章我们学会了"看"信号、"推断"信号、"优化"参数、"跟踪"系统、"权衡"复杂度。这一章回答一个革命性的问题：**怎样让模型自动学习特征，而不是手工设计？** 这就是深度学习的核心——表示学习。你会发现，CNN的卷积核就是可学习的滤波器，RNN的隐状态就是自动提取的特征。深度学习不是一个全新的理论，而是前面所有思想的自然延伸。

## 6.1 从手工特征到自动特征

### 直觉类比

在传统机器学习中，你需要手工设计特征。比如识别猫：

```
手工特征：
- 计算边缘（用Sobel滤波器）
- 计算纹理（用Gabor滤波器）
- 计算颜色直方图
- ...然后把这些特征送给分类器
```

深度学习的思想是：**让网络自动学习这些特征**。

### 数值示例

```
第1层：学到边缘检测（像Sobel滤波器）
第2层：学到纹理（边缘的组合）
第3层：学到部分（纹理的组合）
第4层：学到物体（部分的组合）
```

每一层都在前一层的基础上构建更高级的特征。

### 核心公式

**多层感知机（MLP）：**

$$h_1 = \sigma(W_1 x + b_1)$$
$$h_2 = \sigma(W_2 h_1 + b_2)$$
$$y = W_3 h_2 + b_3$$

**人话解释：** 每一层都是前一层的非线性变换。通过堆叠多层，网络能学到越来越复杂的特征。

## 6.2 卷积神经网络（CNN）

### 直觉类比

CNN的卷积核就是可学习的滤波器。第1章我们学过固定的滤波器（如低通滤波器）。CNN让这些滤波器自动学习。

### 数值示例

```
固定滤波器（第1章）：
  低通滤波器 = [[0.25, 0.25], [0.25, 0.25]]（手工设计）

CNN卷积核（第6章）：
  卷积核 = [[0.1, -0.2], [0.3, 0.05]]（自动学习）
```

### 核心公式

**卷积操作：**

$$y[i,j] = \sum_{u,v} w[u,v] \cdot x[i+u, j+v] + b$$

**人话解释：** 对图像的每个位置，用卷积核做加权求和。卷积核通过反向传播自动学习。

## 6.3 循环神经网络（RNN）

### 直觉类比

RNN处理序列数据。它维护一个"隐状态"，随着时间更新。这就像第4章的卡尔曼滤波，但参数是可学习的。

### 数值示例

```
时间1: 输入=5, 隐状态=0 → 新隐状态=tanh(W_h*0 + W_x*5) = 0.95
时间2: 输入=3, 隐状态=0.95 → 新隐状态=tanh(W_h*0.95 + W_x*3) = 0.88
时间3: ...继续...
```

### 核心公式

**RNN隐状态更新：**

$$h_t = \tanh(W_h h_{t-1} + W_x x_t + b_h)$$
$$y_t = W_y h_t + b_y$$

**人话解释：** 新的隐状态是前一个隐状态和当前输入的非线性组合。这就是第4章卡尔曼滤波的推广。

## 6.4 从浅层到深层

### 概念对照表

| 浅层模型 | 深层模型 | 关键差异 |
|---------|---------|---------|
| 手工特征 | 自动特征 | 从人工设计→自动学习 |
| 线性分类器 | 多层非线性 | 从线性→非线性 |
| 全局优化 | 局部优化 | 从凸→非凸 |

### 反直觉点拨

**常见误解：** "深度学习就是堆叠更多层"

**正确理解：** 深度学习的关键是**表示学习**——每一层学到的特征都被下一层使用。简单地堆叠层数不一定有帮助；关键是每一层学到有用的特征。

**常见误解：** "深度学习不需要理解DSP和统计学"

**正确理解：** CNN的卷积核就是滤波器，RNN的隐状态就是状态空间模型。理解这些基础能帮你更好地设计和调试深度学习模型。

## 6.5 本章小结

**核心要点：**

1. **表示学习是关键** — 深度学习的力量来自自动学习特征，而不是手工设计。

2. **CNN和RNN是DSP的推广** — CNN的卷积核是可学习的滤波器，RNN的隐状态是可学习的状态转移。

3. **从固定到可学习的演化** — 这是贯穿全书的主题：从固定的公式到可学习的参数。
