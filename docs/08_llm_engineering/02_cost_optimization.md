# 8.2 成本优化

**核心问题：** 如何降低LLM应用的成本？

---

## 成本来源

### 1. API调用费用

按token数计费。

**例子：**
- GPT-4：$0.03/1K输入tokens，$0.06/1K输出tokens
- Claude：$3/1M输入tokens，$15/1M输出tokens

### 2. 计算资源

自部署模型的GPU成本。

### 3. 存储

向量数据库、缓存等存储成本。

---

## 优化策略

### 1. 使用更便宜的模型

```
GPT-4 → GPT-3.5 Turbo
成本降低 10倍
```

### 2. 缓存

缓存相同查询的结果。

```
第一次查询：调用API，成本$0.01
第二次查询：从缓存读取，成本$0
```

### 3. 批处理

一次处理多个请求。

```
单个请求：延迟高，成本高
批处理：延迟低，成本低
```

### 4. 提示优化

简化提示，减少token数。

```
长提示：1000 tokens，成本$0.03
短提示：100 tokens，成本$0.003
```

---

## 成本分析

### 计算成本

```
月成本 = 日均请求数 × 平均token数 × 单价
```

### 例子

```
日均请求数：10,000
平均token数：500
单价：$0.001/1K tokens

月成本 = 10,000 × 500 × 0.001 / 1000 × 30 = $150
```

---

## 本节小结

成本优化的关键：
- 选择便宜的模型
- 使用缓存
- 批处理
- 优化提示
