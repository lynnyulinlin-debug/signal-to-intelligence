## 关键概念速查

| 概念 | 公式 | 直观理解 |
|------|------|---------|
| 自注意力 | $\text{Attention}(Q,K,V) = \text{softmax}(\frac{QK^T}{\sqrt{d_k}})V$ | 计算位置间相似度，加权求和 |
| 多头注意力 | $\text{MultiHead}(Q,K,V) = \text{Concat}(\text{head}_1,...,\text{head}_h)W^O$ | 多个注意力头学习不同关系 |
| 位置编码 | $PE(pos,2i) = \sin(\frac{pos}{10000^{2i/d}})$ | 用正弦波编码位置信息 |

## 常见问题

**Q: 为什么要用正弦位置编码而不是学习的位置向量？**
A: 正弦编码有两个优势：(1) 能自动泛化到更长的序列；(2) 不同频率的组合能编码相对位置信息。

**Q: 多头注意力中，每个头的维度是多少？**
A: 如果模型维度是 $d_{model}$，头数是 $h$，则每个头的维度是 $d_{model}/h$。

**Q: 自注意力的时间复杂度是多少？**
A: $O(n^2 d)$，其中 $n$ 是序列长度，$d$ 是维度。这是Transformer的主要计算瓶颈。

## 关键连接点

### 傅里叶变换 → 位置编码

```
傅里叶变换：用不同频率的正弦波表示信号
                    ↓
位置编码：用不同频率的正弦波表示位置
```

**启示：** 位置编码就是把位置"傅里叶变换"。

### Transformer → LLM

```
Transformer：通用的序列模型
                    ↓
LLM：用Transformer + 大规模预训练
```

**启示：** LLM就是大规模预训练的Transformer。
