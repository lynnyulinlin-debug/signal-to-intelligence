# 4.4 完整架构

**核心问题：** Transformer的完整架构是什么？

---

## Transformer块

### 结构

```
输入
  ↓
多头自注意力
  ↓
残差连接 + 层归一化
  ↓
前馈网络（两层全连接）
  ↓
残差连接 + 层归一化
  ↓
输出
```

### 关键组件

**多头自注意力：** 学习位置之间的关系

**前馈网络：** 
$$\text{FFN}(x) = \max(0, xW_1 + b_1)W_2 + b_2$$

**残差连接：** 
$$\text{output} = \text{sublayer}(x) + x$$

**层归一化：** 
$$\text{LayerNorm}(x) = \gamma \frac{x - \mu}{\sigma} + \beta$$

---

## 编码器-解码器架构

### 编码器

多个Transformer块堆叠。

**作用：** 把输入序列编码成上下文表示。

### 解码器

多个Transformer块堆叠，但自注意力只看前面的位置（因果注意力）。

**作用：** 逐个生成输出序列。

### 交叉注意力

解码器中的注意力看编码器的输出。

**作用：** 让解码器关注输入的相关部分。

---

## 完整流程

### 例子：机器翻译

```
输入：英文句子
  ↓
编码器：处理英文，生成上下文表示
  ↓
解码器：逐个生成法文单词
  - 自注意力：看已生成的法文
  - 交叉注意力：看英文上下文
  ↓
输出：法文句子
```

---

## 本节小结

Transformer的完整架构：
- 多头自注意力 + 前馈网络
- 残差连接 + 层归一化
- 编码器-解码器结构
