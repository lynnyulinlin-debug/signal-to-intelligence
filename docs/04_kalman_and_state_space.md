# 第4章：卡尔曼滤波与状态空间

## 导读

前三章我们学会了"看"信号、"推断"信号、"优化"参数。这一章回答一个关键问题：**怎样跟踪一个随时间变化的系统？** 卡尔曼滤波是答案。更重要的是，你会发现RNN和LSTM的隐状态更新机制，本质上就是卡尔曼滤波的现代版本——从固定的状态转移矩阵到可学习的神经网络。

## 4.1 状态空间模型

### 直觉类比

想象你在追踪一个移动的目标（比如飞机）。你不能直接看到它的位置和速度，只能通过雷达观测到一个有噪声的位置。

你需要维护两个信息：
- **状态**：目标的位置和速度
- **观测**：雷达给出的位置（有噪声）

状态空间模型就是用数学语言描述这个过程。

### 数值示例

```
时间1:
  真实状态: 位置=100m, 速度=10m/s
  观测: 位置=102m（有噪声）
  
时间2:
  预测状态: 位置=110m, 速度=10m/s（基于匀速运动）
  观测: 位置=108m（有噪声）
  
时间3:
  ...继续...
```

### 核心公式

**状态空间模型：**

$$x_{k+1} = F x_k + w_k \quad \text{(状态转移)}$$
$$z_k = H x_k + v_k \quad \text{(观测模型)}$$

**人话解释：** 
- 第一个方程说"新的状态由旧的状态通过矩阵F转移而来，加上过程噪声"
- 第二个方程说"观测是状态通过矩阵H投射而来，加上测量噪声"

### 代码验证

```python
import numpy as np

# 状态转移矩阵（匀速运动）
F = np.array([[1, 1],    # 位置 = 旧位置 + 速度
              [0, 1]])    # 速度 = 旧速度

# 观测矩阵（只能观测位置）
H = np.array([[1, 0]])

# 初始状态
x = np.array([[0], [1]])  # 位置=0, 速度=1

# 模拟5步
for k in range(5):
    x = F @ x
    z = H @ x + np.random.randn(1, 1) * 0.1
    print(f"时间{k}: 位置={x[0,0]:.1f}, 观测={z[0,0]:.1f}")
# 输出：
# 时间0: 位置=1.0, 观测=1.1
# 时间1: 位置=2.0, 观测=2.0
# ...
```

## 4.2 卡尔曼滤波：最优估计

### 直觉类比

你有两个信息源：
1. **预测**：基于物理模型（目标应该在这里）
2. **观测**：基于传感器（传感器说目标在这里）

卡尔曼滤波的思想是：**根据两者的可信度，加权平均**。

如果你的预测模型很准确，就更相信预测；如果传感器很准确，就更相信观测。

### 数值示例

```
预测位置: 100m, 预测误差: 1m²
观测位置: 102m, 观测误差: 4m²

卡尔曼增益 = 1 / (1 + 4) = 0.2
更新位置 = 100 + 0.2 * (102 - 100) = 100.4m
```

更新后的位置更接近预测（因为预测更可信）。

### 核心公式

**卡尔曼滤波（预测-更新）：**

预测步骤：
$$x_{k|k-1} = F x_{k-1|k-1}$$
$$P_{k|k-1} = F P_{k-1|k-1} F^T + Q$$

更新步骤：
$$K_k = P_{k|k-1} H^T (H P_{k|k-1} H^T + R)^{-1}$$
$$x_{k|k} = x_{k|k-1} + K_k (z_k - H x_{k|k-1})$$
$$P_{k|k} = (I - K_k H) P_{k|k-1}$$

**人话解释：** 
- 预测步骤：根据状态转移模型预测新的状态和不确定性
- 更新步骤：根据观测调整预测，调整幅度由卡尔曼增益 $K_k$ 决定

## 4.3 从卡尔曼滤波到RNN

### 概念对照表

| 卡尔曼滤波 | RNN | LSTM | 关键差异 |
|----------|-----|------|---------|
| 固定的F矩阵 | 可学习的W_h | 可学习的W_h | 从固定→可学习 |
| 固定的H矩阵 | 可学习的W_x | 可学习的W_x | 从固定→可学习 |
| 预测-更新递归 | 隐状态更新 | 门控机制 | 从简单→复杂 |
| 线性系统 | 非线性系统 | 非线性+门控 | 从线性→非线性 |

### 反直觉点拨

**常见误解：** "RNN就是卡尔曼滤波的神经网络版本"

**正确理解：** RNN的隐状态更新确实像卡尔曼滤波的递归，但有关键区别：
- 卡尔曼滤波是**线性**的，有**最优性保证**
- RNN是**非线性**的，没有最优性保证，但能学习更复杂的模式

**常见误解：** "LSTM的门控机制和卡尔曼增益是一样的"

**正确理解：** 都是"决定相信多少新信息"，但LSTM的门控是**学习得到的**，而卡尔曼增益是**根据噪声方差计算的**。

### 代码对比

**卡尔曼滤波（固定参数）**
```python
# 预测
x_pred = F @ x
P_pred = F @ P @ F.T + Q

# 更新
K = P_pred @ H.T @ np.linalg.inv(H @ P_pred @ H.T + R)
x = x_pred + K @ (z - H @ x_pred)
P = (np.eye(2) - K @ H) @ P_pred
```

**RNN（可学习参数）**
```python
# 隐状态更新
h_t = np.tanh(W_h @ h_prev + W_x @ x_t + b_h)

# 输出
y_t = W_y @ h_t + b_y
```

**LSTM（门控机制）**
```python
# 遗忘门：决定保留多少旧信息
f_t = sigmoid(W_f @ [h_prev, x_t] + b_f)

# 输入门：决定接收多少新信息
i_t = sigmoid(W_i @ [h_prev, x_t] + b_i)

# 候选值
c_tilde = tanh(W_c @ [h_prev, x_t] + b_c)

# 更新细胞状态
c_t = f_t * c_prev + i_t * c_tilde
```

## 4.4 本章小结

**核心要点：**

1. **状态空间模型是通用的** — 从飞机追踪到语言建模，都可以用状态空间模型描述。

2. **卡尔曼滤波是最优的** — 对于线性系统和高斯噪声，卡尔曼滤波给出最小方差估计。

3. **RNN/LSTM是卡尔曼滤波的推广** — 从固定的线性系统到可学习的非线性系统。LSTM的门控机制是对卡尔曼增益的推广。
