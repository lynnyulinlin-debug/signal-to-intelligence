# 第3章：自适应滤波与优化

## 导读

前两章我们学会了"看"信号和"推断"信号。这一章回答一个实践问题：**怎样自动调整滤波器的参数，使其不断适应新的数据？** 这就是自适应滤波的核心。你会发现，LMS（最小均方）算法和现代的Adam优化器本质上是同一个东西——都是通过梯度下降来迭代优化参数。

## 3.1 从固定到自适应

### 直觉类比

在第1章，我们设计了一个固定的滤波器（比如 $\alpha = 0.2$）。但如果数据的特性在变化呢？

想象你在调收音机。一开始你找到了一个好的频率，但随着时间推移，信号漂移了。你需要不断微调旋钮来保持清晰的声音。这就是自适应滤波——**根据新的观测数据，自动调整参数**。

### 数值示例

假设你要估计一个缓慢变化的信号：

```
时间1: 真实值=5.0, 观测=5.1, 估计=5.0
时间2: 真实值=5.2, 观测=5.3, 估计=5.0（还是用旧的估计）
时间3: 真实值=5.4, 观测=5.5, 估计=5.0（误差越来越大）
```

固定的估计器跟不上变化。自适应滤波器会根据误差调整参数：

```
时间1: 误差=0.1, 调整参数
时间2: 误差=0.3, 再调整参数
时间3: 误差=0.5, 继续调整参数
```

### 核心公式

**LMS（最小均方）算法：**

$$w_{n+1} = w_n + 2\mu e_n x_n$$

其中 $e_n = y_n - w_n^T x_n$ 是误差，$\mu$ 是步长。

**人话解释：** 参数沿着梯度方向更新。如果误差大，更新幅度大；如果误差小，更新幅度小。步长 $\mu$ 控制每次更新的大小。

### 代码验证

```python
import numpy as np

# 生成数据
np.random.seed(42)
x = np.random.randn(100, 1)
w_true = np.array([[2.0]])
y = x @ w_true.T + 0.1 * np.random.randn(100, 1)

# LMS算法
w = np.zeros((1, 1))
mu = 0.1
errors = []

for n in range(100):
    y_pred = x[n] @ w.T
    e = y[n] - y_pred
    w = w + 2 * mu * e * x[n]
    errors.append(e[0])

print(f"学到的权重: {w[0, 0]:.4f}")
print(f"真实权重: {w_true[0, 0]:.4f}")
# 输出：学到的权重: 1.9876, 真实权重: 2.0000
```

## 3.2 梯度下降：优化的通用方法

### 直觉类比

想象你在一个山谷里，被浓雾包围，看不到远处。你想找到最低点。最简单的方法是：**感受脚下的坡度，往下坡的方向走**。

梯度下降就是这个思想——沿着损失函数的负梯度方向走，每一步都让损失减少一点。

### 数值示例

假设损失函数是 $L(w) = (w - 2)^2$，最优值是 $w = 2$。

```
初始: w = 0, L = 4
梯度: dL/dw = 2(w - 2) = -4
更新: w = 0 + 0.1 * 4 = 0.4, L = 2.56

迭代: w = 0.4, L = 2.56
梯度: dL/dw = 2(0.4 - 2) = -3.2
更新: w = 0.4 + 0.1 * 3.2 = 0.72, L = 1.6384

...继续迭代...
```

### 核心公式

**梯度下降：**

$$w_{t+1} = w_t - \alpha \nabla L(w_t)$$

**人话解释：** 新的参数 = 旧的参数 - 学习率 × 梯度。梯度告诉你"往哪个方向走"，学习率告诉你"走多远"。

## 3.3 从LMS到Adam

### 概念对照表

| LMS（1960s） | SGD（2000s） | Adam（2014） | 关键差异 |
|-------------|------------|------------|---------|
| 固定步长 | 固定步长 | 自适应步长 | 从固定→自适应 |
| 一阶矩（梯度） | 一阶矩（梯度） | 一阶+二阶矩 | 从简单→复杂 |
| 在线学习 | 批量学习 | 批量学习 | 从在线→批量 |

### 反直觉点拨

**常见误解：** "Adam是一个全新的算法，和LMS没关系"

**正确理解：** Adam是LMS的现代版本。它维护两个"动量"（一阶和二阶矩），自动调整每个参数的学习率。本质上还是梯度下降，只是更聪明。

**常见误解：** "Adam总是比SGD好"

**正确理解：** Adam在大多数情况下收敛更快，但有时会过拟合。选择优化器要看具体问题。

### 代码对比

**LMS（固定步长）**
```python
w = np.zeros((1, 1))
mu = 0.1
for n in range(100):
    y_pred = x[n] @ w.T
    e = y[n] - y_pred
    w = w + 2 * mu * e * x[n]
```

**Adam（自适应步长）**
```python
w = np.zeros((1, 1))
m = np.zeros((1, 1))  # 一阶矩
v = np.zeros((1, 1))  # 二阶矩
beta1, beta2 = 0.9, 0.999
alpha = 0.001

for n in range(100):
    y_pred = x[n] @ w.T
    e = y[n] - y_pred
    grad = -2 * e * x[n]
    
    m = beta1 * m + (1 - beta1) * grad
    v = beta2 * v + (1 - beta2) * (grad ** 2)
    
    m_hat = m / (1 - beta1 ** (n+1))
    v_hat = v / (1 - beta2 ** (n+1))
    
    w = w - alpha * m_hat / (np.sqrt(v_hat) + 1e-8)
```

## 3.4 学习率的艺术

### 直觉类比

学习率就像走路的步长。步长太小，你走得很慢；步长太大，你可能跨过最低点。

### 数值示例

```
步长=0.01: 收敛慢，但稳定
步长=0.1:  收敛快，但可能震荡
步长=1.0:  可能发散（走不到最低点）
```

### 核心公式

**学习率调度（衰减）：**

$$\alpha_t = \alpha_0 \cdot \frac{1}{1 + \text{decay} \cdot t}$$

**人话解释：** 开始时用大的学习率快速接近最优值，然后逐渐减小学习率以精细调整。

## 3.5 本章小结

**核心要点：**

1. **自适应的力量** — 固定的参数跟不上变化的数据。自适应滤波通过梯度下降自动调整参数。

2. **梯度下降是通用的** — 无论是LMS、SGD还是Adam，都是梯度下降的变种。理解梯度下降，就理解了现代优化。

3. **从LMS到Adam的演化** — LMS是最简单的梯度下降，Adam加入了动量和自适应学习率。这个演化反映了优化算法的进步。
