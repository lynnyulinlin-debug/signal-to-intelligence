# 3.4 为什么Transformer更好

**核心问题：** Transformer相比RNN有什么优势？

---

## RNN的根本问题

### 1. 顺序处理

RNN必须按时间顺序处理，无法并行化。

```
时刻1 → 时刻2 → 时刻3 → ...
```

**问题：** 训练慢，无法充分利用GPU。

### 2. 长期依赖困难

即使有LSTM，学习长期依赖仍然困难。

**原因：** 信息必须通过多个时刻的隐状态传递。

### 3. 上下文窗口有限

RNN的隐状态大小固定，无法处理很长的序列。

---

## Transformer的创新

### 自注意力机制（Self-Attention）

**核心思想：** 每个位置可以直接看到所有其他位置。

```
位置1 ← 看到所有位置
位置2 ← 看到所有位置
位置3 ← 看到所有位置
...
```

**优势：**
- 完全可并行化
- 任意两个位置之间的距离都是1（不是序列长度）
- 容易学习长期依赖

### 数学表达

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right) V$$

其中：
- $Q$：查询（Query）
- $K$：键（Key）
- $V$：值（Value）

---

## Transformer vs RNN

| 特性 | RNN | Transformer |
|------|-----|-------------|
| 并行化 | 不能 | 完全可并行 |
| 训练速度 | 慢 | 快10倍+ |
| 长期依赖 | 困难 | 容易 |
| 内存占用 | 低 | 高 |
| 上下文长度 | 有限 | 很长 |

---

## Transformer的架构

### 编码器-解码器结构

```
输入序列
  ↓
编码器（多层Transformer块）
  ↓
解码器（多层Transformer块）
  ↓
输出序列
```

### Transformer块

```
多头自注意力
  ↓
残差连接 + 层归一化
  ↓
前馈网络
  ↓
残差连接 + 层归一化
```

---

## 为什么Transformer成为主流

### 1. 训练效率高

- 完全可并行化
- 可以用大批大小
- 训练速度快

### 2. 性能好

- 在NLP任务上超越RNN
- 能学习长期依赖
- 涌现能力（大模型）

### 3. 易于扩展

- 参数量可以任意增加
- 性能随参数量单调增长（Scaling Laws）

### 4. 通用性强

- 不仅适用于NLP
- 也适用于计算机视觉（ViT）
- 也适用于多模态（CLIP）

---

## 本节小结

Transformer相比RNN的优势：
- 自注意力机制
- 完全可并行化
- 容易学习长期依赖
- 易于扩展到大模型
