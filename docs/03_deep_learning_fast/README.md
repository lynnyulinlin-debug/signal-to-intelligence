## 关键概念速查

| 概念 | 特点 | 适用场景 |
|------|------|---------|
| CNN | 局部连接、权重共享、平移不变性 | 图像处理 |
| RNN | 循环连接、隐状态、时间依赖 | 序列处理 |
| Transformer | 自注意力、并行处理、长距离依赖 | 序列处理、NLP |

## 常见问题

**Q: 为什么CNN对图像处理特别有效？**
A: CNN利用了图像的局部结构特性，通过卷积核提取局部特征，这与人类视觉系统的工作方式相似。

**Q: RNN为什么会有梯度消失问题？**
A: 在反向传播时，梯度通过多个时间步相乘，如果梯度小于1，会指数衰减。

**Q: Transformer为什么比RNN更好？**
A: Transformer使用自注意力机制，任意两个位置之间的距离都是1，避免了梯度消失问题，同时支持完全并行化。

## 关键连接点

### CNN → DSP

```
DSP中的卷积：y[n] = Σ x[m] * h[n-m]
                    ↓
CNN中的卷积核：可学习的滤波器
```

**启示：** CNN就是学习最优的滤波器。

### RNN → 状态空间

```
状态空间模型：x_{t+1} = A x_t + B u_t
                    ↓
RNN：h_t = f(h_{t-1}, x_t)
```

**启示：** RNN是可学习的状态空间模型。

### Transformer → LLM

```
Transformer：通用的序列模型
                    ↓
LLM：用Transformer + 大规模预训练
```

**启示：** LLM就是大规模预训练的Transformer。
